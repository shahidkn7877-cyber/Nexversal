# Nexversal

> **Official Brand Domain:** [https://nexversal.bond](https://nexversal.bond)

**Nexversal** is a modern, professional full-stack SEO platform engineered with Next.js App Router, TypeScript, Tailwind CSS, PostgreSQL, and Vitest.

---

## Core Capabilities

- **Content SEO Analyzer**: Deterministic on-page SEO diagnostics, heading hierarchy auditing, keyword distribution, and mobile readability analysis.
- **Live SEO URL Audit**: Real-time HTTP/HTTPS page crawler evaluating metadata, canonical tags, Open Graph, image alt attributes, and robots directives.
- **Keyword Research Engine**: Search volume estimation, keyword difficulty (KD), CPC competition metrics, and intent categorization.
- **Audit Reports & History**: User-isolated persistent audit records with CSV/JSON exports.
- **Admin Security Console**: Server-side RBAC protection, provider management, and audit log telemetry.

---

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Database**: PostgreSQL with Prisma ORM
- **Styling**: Tailwind CSS with custom dark mode design system
- **Testing**: Vitest with unit, integration, and security test suites

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shahidkn7877-cyber/Nexversal.git
   cd Nexversal
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   ```bash
   cp .env.example .env
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
